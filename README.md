# Student Performance Analysis

## Project Overview

This beginner-level Excel project analyses the marks and academic performance of five students across three subjects: Mathematics, English, and Science.

## Objectives

* Calculate each student's total marks.
* Calculate student percentages.
* Identify the average, highest, and lowest total marks.
* Compare student percentages using a column chart.
* Present key findings in a clear and organised format.

## Tools Used

* Microsoft Excel

## Excel Skills Demonstrated

* SUM formula
* AVERAGE formula
* MAX and MIN formulas
* Percentage calculations
* Basic data formatting
* Column chart creation
* Data analysis and interpretation

## Key Findings

* Highest total marks: 271 out of 300.
* Lowest total marks: 210 out of 300.
* Average total marks: 243.2 out of 300.
* Highest percentage: 90.33%.

## Files Included

* Student_Performance_Analysis.xlsx — Excel workbook containing the sample data, calculations, summary, and chart.

## Conclusion

This project demonstrates basic Excel skills for calculating, summarising, and visualising student performance data.

Note: The project uses sample student data for learning purposes.
